# Порядок — список задач

Минималистичное приложение для управления задачами с сохранением в localStorage.

## Реализованные функции

- **Добавление задач** — через кнопку или Enter, с валидацией (максимум 200 символов, обрезка пробелов)
- **Отметка выполнения** — чекбокс с визуальным отличием выполненных задач (зачёркнутый текст, приглушённый цвет)
- **Удаление задач** — кнопка удаления у каждой задачи с доступным именем
- **Фильтрация** — «Все», «Активные», «Выполненные»
- **Поиск по названию** — мгновенный поиск по вхождению подстроки, без учёта регистра, с кнопкой очистки и Escape
- **Приоритеты** — три уровня: «Обычный», «Важный», «Высокий» с цветовыми бейджами
- **Сроки выполнения** — назначение календарной даты, отображение «сегодня», «завтра», «просрочена», редактирование inline
- **Счётчик задач** — с правильным склонением («Осталась 1 задача», «Осталось 2 задачи», «Осталось 5 задач»)
- **Счётчик результатов поиска** — «Найдено: N» при непустом запросе
- **Сохранение в localStorage** — данные восстанавливаются после обновления страницы
- **Пустые состояния** — разные сообщения для пустого списка, отсутствия активных/выполненных задач, и «Ничего не найдено»
- **Предупреждение об ошибке записи** — ненавязчивое уведомление, если localStorage недоступен
- **Адаптивность** — работает на 360px, 768px, 1440px без горизонтального скролла
- **Доступность** — клавиатурное управление, focus-visible, ARIA-атрибуты, семантическая вёрстка
- **Визуальный стиль** — печатные шрифты (Merriweather, Libre Baskerville), текстурный фон, расширенная форма ввода (max-width 880px)

## Хранение задач

Задачи сохраняются в `localStorage` под ключом `poryadok.tasks.v1`.

Модель задачи:
```ts
type Task = {
  id: string;           // crypto.randomUUID()
  title: string;        // до 200 символов
  completed: boolean;   // статус выполнения
  createdAt: string;    // ISO-строка
  dueDate: string | null;  // YYYY-MM-DD или null
  priority: 'normal' | 'important' | 'high';
};
```

**Важные замечания:**
- Данные хранятся **только в текущем браузере** для текущего адреса сайта (origin)
- Данные **не синхронизируются** между устройствами или браузерами
- Данные **могут быть удалены** при очистке кэша/данных браузера
- При повреждённых данных приложение не падает — загружается пустой список
- При ошибке записи показывается предупреждение, но приложение продолжает работать в памяти

```

  components/
    TaskForm.tsx       # Форма добавления задачи
    TaskFilters.tsx    # Фильтры (Все/Активные/Выполненные)
    TaskList.tsx       # Список задач

  types/

  App.tsx              # Главный компонент
  main.tsx             # Точка входа

```

## Ограничения

- Нет аккаунтов и авторизации
- Нет синхронизации между устройствами
- Нет редактирования названия задачи (только добавление/выполнение/удаление/срок/приоритет)
- Нет drag-and-drop, календаря, уведомлений
- Нет сортировки по приоритету (приоритет работает независимо)

## Публикация на Vercel

1. Загрузите проект в GitHub-репозиторий
2. В Vercel: **Add New Project** → выберите репозиторий
3. Настройки сборки (автоопределяются):
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
4. Переменные окружения не требуются
5. Нажмите **Deploy**
